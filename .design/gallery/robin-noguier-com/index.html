06 Correction Plan

What holds the grade back, and what to keep.

  • Tokenize the CSS. CSS tokenization scored 50/100 — the single biggest deduction. The semantic variables came back malformed (success/warning/error: [object Object]) and values read as hard-coded. Promote color, type, and the 2px spacing scale to named custom properties.
  • Fill in the type scale. Typography 80/100: five sizes across three families (Times, Silka, Eksell) with a large gap between the 120px display and the 14–20px body. Add mid-scale steps and consolidate to a named ramp.
  • Keep the color discipline. 100/100. A six-color system — white, black, and pale sage with one slate-blue accent, average saturation 0.095.
  • Keep the flat, disciplined base. Spacing 100/100, border-radius 100/100 (4 / 32px), accessibility 100/100. Flat material, no shadows, hairline borders.
