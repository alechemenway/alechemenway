06 Correction Plan

What holds the grade back, and what to keep.

  • Collapse the type system. Typography scores 40/100 — the biggest drag. 11 font families and 24 distinct sizes (390 → 20px) with everything at weight 400. Pick two workhorses (one editorial serif + one sans) and a named scale; drop the seven single-use faces.
  • Cut the CSS bloat. Tokenization sits at 50/100: 20,149 duplicate declarations, 357 !important rules, and 57% unused CSS. Purge and consolidate; replace overrides with tokens.
  • Set a spacing base unit. Spacing scores 55 — values jump straight from 1px to 125px. Define a 4- or 8-px step ladder so rhythm is predictable.
  • Keep the color and shape discipline. Color 100, Border-radius 100, Accessibility 100 — a black-and-neon palette and consistent 45–50px pills. Note: WCAG shows 0 passing / 0 failing pairs, so the 100% is nominal (no text/background pairs were sampled), not a proven contrast pass.
